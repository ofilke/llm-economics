## Core principle

`llm-economics` trennt konsequent:

1. **direkt messbare Workload-Daten** aus vorhandenen Artefakten,
2. **echte API-Usage** aus Calibration Runs,
3. **abgeleitete Schätzungen** für historische oder zukünftige Szenarien.

Keine Schätzung wird als gemessener Verbrauch ausgegeben.
